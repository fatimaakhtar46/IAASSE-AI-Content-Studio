# IAASSE AI Content Studio

An AI-powered social-media content generation tool developed as part of the **IAASSE Internship Program**.

## Project Overview

The **IAASSE AI Content Studio** helps the communications team create social-media content more efficiently.

Users provide a short brief and select:

* Platform
* Content type
* Tone

The tool then generates:

* Social-media caption
* Hashtags
* Content angles

## Project Goal

The goal of this project is to create a simple AI-powered workflow that helps the communications team turn ideas into clear, engaging, and platform-appropriate social-media content.

## Features

* Simple content brief input
* LinkedIn content generation
* Instagram content generation
* Facebook content generation
* X/Twitter content generation
* Announcement content
* Thought leadership content
* Event invitation content
* Impact story content
* Multiple tone options
* Caption generation
* Hashtag suggestions
* Content-angle suggestions

## How It Works

1. Enter the topic or context.
2. Select the social-media platform.
3. Select the content type.
4. Select the desired tone.
5. Click **Generate Content**.
6. Review and refine the generated output.

## User Testing

The prototype was tested using different combinations of:

* Topics
* Platforms
* Content types
* Tones

User feedback was collected through a Google Form to evaluate the usefulness and quality of the generated content.
